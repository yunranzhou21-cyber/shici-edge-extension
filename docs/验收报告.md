# 阶段 A、文档/PDF 与 v0.7.0 手动搜索验收报告

日期：2026-10-20（Asia/Shanghai）
环境：Windows；Microsoft Edge 155.0.4283.45；独立无头浏览器配置  
状态：阶段 A 实现并完成下述自动化验证；不等同于阶段 B/C 或云端服务全部完成验收。

## 验证边界

浏览器直接加载真实扩展代码，验证 IndexedDB、后台消息、浮窗、管理页及重启持久化。为绕过无头浏览器不能处理的可选 API 权限提示，仅在测试副本中预授予 `http://127.0.0.1/*`。v0.2.0 在普通 HTTP/HTTPS 网页自动显示圆形入口，内容脚本不自动查词；交付清单未添加网络 API 的默认主机权限。

选词触发测试执行了与快捷键处理器相同的脚本注入和消息路径。默认快捷键在 Edge 中成功注册，但自动化没有按真实操作系统组合键验证，因此仍需按安装说明人工检查快捷键冲突和权限提示。

AI 采用核心协议测试与本机受控 HTTP 服务，实际检查了请求、认证头、缓存、测试请求、429 和密钥删除。没有用户云端密钥，没有向真实 Gemini / DeepSeek / OpenRouter 模型发请求。

## v0.5.0 浮窗手动查词验收

- 展开默认显示查词页；输入英文、打开浮窗和切换页签不触发查询、收藏或 API 请求。Enter 和查询按钮可以明确发起查询；无效输入不生成历史。
- 离线查词显示本次词典释义及收藏状态；修改中文后主动收藏，保存为手动来源，计数更新。快速重复点击不会重复提交。
- running 匹配已收藏的 run，显示本次释义及旧记录；追加新的中文释义和原句后，旧首选释义保留。
- 收藏页可用新保存的语境检索；在查词、收藏、设置页签之间切换不丢失本次释义草稿。
- 未命中时允许手动填写释义再收藏；空释义禁用收藏。无微软配置时保留本地释义与收藏状态并显示配置入口，不发送联网请求。
- 使用本机受控微软接口验证实际浮窗联网入口：查询期间可先显示已收藏状态；输入新词立即使旧结果失效，较慢的旧响应不覆盖新词；明确重查显示微软译文并复用缓存，不覆盖已有收藏。
- 收藏在收起浮窗和刷新网页后可检索，Escape 收起及宿主网页无法读取浮窗的隔离检查仍通过。已查看 `artifacts/widget-lookup.png` 中真实浮窗，中文布局与按钮正常。

## v0.4.0 文档/PDF 专项验收

1. 真实鼠标在 PDF 文字层拖动选中 Running，通过查词按钮获得离线释义并收藏，保留原词、文件名、第 2 页、局部原句和文件 SHA-256 指纹。
2. 以 Poppler 参考渲染与 Edge canvas 截图检查布局；文字层可选范围与可见文字对应。验证 150% 缩放以及 PDF 来源字段的备份往返。
3. 从本地 PDF 收藏来源重新打开时提示选择原文件，拒绝不同指纹文件，选择正确文件后定位至第 2 页。
4. 图片/无文字层 PDF 明确提示无 OCR；把登录 HTML 当作 PDF 时拒绝解析，不假装读取成功。
5. 加密 PDF 可在本机输入密码打开，密码输入值随即清空，密码不进入导出数据。
6. 快捷键处理函数能向扩展自己的 PDF 阅读页派发取词消息，无需对扩展页调用内容脚本注入。物理操作系统快捷键仍需用户环境确认。
7. 在线 PDF 加载及微软联网重查通过本机 HTTP 服务验证；外发翻译正文只有所选 Running，不含整个 PDF。保留在线来源 URL 和页码。
8. 跨源 HTML 文档框架中的语义文档正文可取词，焦点框架优先于外层旧选区；内层不生成重复圆形浮标。
9. 右键选词处理函数能打开真实查询并保留可获得的 PDF 页码。原生菜单物理点击未逐 Edge/PDF 阅读器版本验证。

新增 PDF.js 6.4.299（Apache-2.0），解析库、Worker、CMap、字体与 WASM 全部随扩展本机打包，未把用户 PDF 发送给外部服务。原有 23 项网页、收藏、历史、浮框和 API 检查回归通过。本次仅修改本地文件，未执行 GitHub 上传。

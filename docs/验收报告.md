# 阶段 A 与 v0.2.0 网页浮框验收报告

日期：2026-10-19（Asia/Shanghai）  
环境：Windows；Microsoft Edge 155.0.4283.45；独立无头浏览器配置  
状态：阶段 A 实现并完成下述自动化验证；不等同于阶段 B/C 或云端服务全部完成验收。

## 验证边界

浏览器直接加载真实扩展代码，验证 IndexedDB、后台消息、浮窗、管理页及重启持久化。为绕过无头浏览器不能处理的可选 API 权限提示，仅在测试副本中预授予 `http://127.0.0.1/*`。v0.2.0 在普通 HTTP/HTTPS 网页自动显示圆形入口，内容脚本不自动查词；交付清单未添加网络 API 的默认主机权限。

选词触发测试执行了与快捷键处理器相同的脚本注入和消息路径。默认快捷键在 Edge 中成功注册，但自动化没有按真实操作系统组合键验证，因此仍需按安装说明人工检查快捷键冲突和权限提示。

AI 采用核心协议测试与本机受控 HTTP 服务，实际检查了请求、认证头、缓存、测试请求、429 和密钥删除。没有用户云端密钥，没有向真实 Gemini / DeepSeek / OpenRouter 模型发请求。

## v0.2.0 新增验收

- 网页图标默认圆形、收起，不触发查词、历史记录或 API 请求。
- 真实鼠标拖动改变图标坐标，拖动不展开面板；刷新后恢复相同位置。
- 展开面板可搜索英文、中文和遇到的词形，查看收藏语境与来源。
- 收藏列表放在扩展域 iframe 中；宿主网页读取 iframe 文档触发 SecurityError。网页内容脚本不能调用收藏列表、偏好写入和 AI 开关管理消息。
- 图标大小与透明度变更立即作用于网页，刷新后仍保留；隐藏后能从完整设置恢复。
- 浮框修改快捷键入口真实打开浏览器扩展快捷键编辑页；按钮未模拟修改成功。真实物理组合键重新绑定仍保留人工检查边界。
- 原有离线查询、收藏、历史、备份、API 错误处理与浏览器重启持久化均回归通过。

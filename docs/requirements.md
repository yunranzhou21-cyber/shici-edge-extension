# 主动查词与单词记录工具：产品与开发需求

版本：1.0  
日期：2026-10-18  
文档语言：中文  
产品名称：待定  
目标平台：Windows，Microsoft Edge 浏览器扩展

## 1. 给开发 AI 的任务说明

根据本文件实现一个轻量的 Edge 扩展。先完成核心查词与记录闭环，再添加 YouTube 适配。本文没有要求立即上架扩展商店，也没有要求搭建云服务器。

- “必须”表示已确认的产品行为。
- “建议”表示可替换的实现方案，不是用户指定的技术栈。
- “后续”表示预留扩展能力，不阻塞第一版交付。
- 不要擅自加入背单词打卡、学习任务、自动全页生词标记或强制登录。
- 遇到权限、字幕、文档阅读器限制，应提供明确降级提示，不得假装支持。
- 核心信息是原词和中文释义。上下文、来源、页码等获取困难时允许为空，不得阻塞查词和收藏。

## 2. 产品目标与定位

用户在阅读英文文章、观看 YouTube 或阅读课件时，主动选中不懂的英文，通过快捷键查询中文释义，选择是否收藏，以后可以搜索找回。

产品偏向即时理解和个人记录，不以系统学习、复习训练为主要目标。用户认为 Relingo 的学习导向较强，因此本产品必须由用户主动触发，不自动翻译或标记整页生词。

## 3. 已确认决策

| 项目 | 已确认需求 |
| --- | --- |
| 设备 | Windows 电脑 |
| 形态 | 优先开发 Edge 浏览器扩展 |
| 场景 | 网页文章、YouTube 英文字幕、Edge 中打开的 PDF/PPT 课件 |
| 触发 | 选中英文后，按快捷键呼出翻译 |
| 展示 | 先显示简短中文释义；需要时点击“解释原句” |
| 收藏 | 用户手动决定，不将每次查询自动设为收藏 |
| 收藏检查 | 每次查询自动检查该词是否已收藏 |
| 已收藏时 | 显示本次释义，并允许展开旧收藏记录 |
| 词形 | 尽量合并 run/runs/running/ran 等词形，保留实际遇到的形式 |
| 历史 | 保留查询历史，与收藏分开，允许清除 |
| 视频 | 查词时暂停，关闭卡片后由用户手动继续 |
| 搜索 | 支持英文、中文搜索；希望按来源查找，但复杂时可延期 |
| 数据 | 本地优先保存，云同步为后续选项 |
| 成本 | 优先无 API 调用费的本地词典，微软免费档为备选 |
| AI | 预留 API 设置及调用入口，用户自行填写，不内置开发者共享密钥 |

说明：用户最初接受联网翻译，后续提出完全免费方案。当前建议架构为“本地词典优先、可配置联网备用”；联网可用不代表每次查询必须联网。

## 4. 交付阶段与范围

### 阶段 A：核心 MVP

必须包含：网页选词与快捷键、简短释义、收藏状态检查、手动收藏、查询历史、本地单词本、中英文搜索、导入导出、API 配置界面。

词形识别先覆盖可靠的常见形式，保留不确定情况。AI 设置和接口必须预留；是否在阶段 A 完成所有服务商的实际适配可以分步交付，未实现的服务商必须明确标记，不能显示虚假的连接成功。

### 阶段 B：YouTube

适配可读取英文字幕的视频，提供可以选词的字幕区域，记录时间点，主动查词时暂停视频。属于早期目标，但不应阻塞阶段 A。

### 阶段 C：课件与其他扩展

分别验证 Edge PDF 阅读器、网页 PPT 阅读器，必要时使用扩展自己的文档阅读页。后续再支持桌面 PowerPoint、Acrobat 等软件，以及可选云同步。

## 5. 核心操作流程

1. 用户选中英文单词或短语。
2. 用户按可配置的快捷键。
3. 扩展读取本次选区及可获取的局部上下文。
4. 标准化查询词，检查本地收藏；该检查不依赖翻译网络成功。
5. 优先查询本地词典；未命中时，根据用户配置使用联网备用或提示未找到。
6. 展示本次简短释义、原词、收藏状态。
7. 用户可收藏、查看旧记录、追加当前语境，或点击“解释原句”。
8. 本次查询进入历史。关闭卡片后返回原任务。

无选区时提示“请先选中英文单词或短语”，不读取剪贴板作为默认替代，不记录空查询。

## 6. 详细功能

### F01 主动快捷键查词

- 不因悬停、选中或打开网页自动调用翻译。
- 快捷键可修改；默认组合由开发时检查冲突后选择，不作为固定产品要求。
- 普通页面尽量在选区附近显示轻量浮窗。
- 支持关闭按钮和 Escape。不得覆盖原页面主要操作。
- 不在密码输入框或其他敏感输入区域取词。

### F02 简短释义

- 必须显示用户实际选中的原词和中文释义。
- 若有可靠数据，可补充基本词形、词性和音标；这些不阻塞基础结果。
- 单词和短语都可查询，但本地词典不承诺覆盖任意句子。
- 展示加载、未命中、无网络、服务配置缺失、调用失败等状态。
- 无上下文时给出一般释义，不编造当前语境的唯一含义。

### F03 收藏与收藏检查

- 查询开始即检查本地收藏状态，显示“未收藏”或“已收藏”。
- 未收藏时提供收藏按钮；收藏前允许用户修改释义。
- 已收藏时仍显示本次查询结果，不用旧释义强行替换。
- 提供“查看已有记录”和“追加本次原句/释义”。
- 不因再次查词自动覆盖已有释义。
- 同词多语境可归在同一词条下，保留多条记录。
- 最小可收藏内容仅需原词和中文释义。

### F04 词形归并

- 支持可靠的词形还原，如 running → run、ran → run。
- 保留原始拼写与标准词形；短语不做粗暴词尾裁剪。
- saw 等可能对应多个词义或词形的情况，需结合可靠词典/上下文判断；无法判断时不强行合并。
- MVP 允许不确定形式单独保存，后续增加手动合并。

### F05 查询历史

- 查过但未收藏的内容也进入历史。
- 历史和收藏是不同状态，不能混为一谈。
- 可从历史收藏，支持删除历史和清空历史。
- 清空历史不会删除收藏；删除收藏不会自动清除历史。
- 建议重复查询更新次数和最后查询时间，保留独立语境信息。

### F06 单词本与搜索

- 点击扩展图标可进入单词本、历史和设置。
- 搜索英文原词、标准词形及中文释义。
- 展示、编辑和删除收藏；建议默认按最近收藏排序。
- 可获取来源时，支持回到原网页或 YouTube 时间点。
- 来源筛选为增强项；来源缺失不得导致记录无法搜索。

### F07 YouTube

- 只在用户主动查词时暂停，不因普通选择或浏览自动暂停。
- 关闭翻译卡片后不自动播放，包括视频原本已暂停的情况。
- 建议提供可选词字幕面板，避免依赖播放画面中难以选择的字幕。
- 可获取时保存视频标题、链接、字幕原句及秒级时间点。
- 无英文字幕、字幕不可读取或页面改版时，提示限制，保留手动输入查询入口。
- 不承诺对所有视频自动语音识别；不默认上传音视频。

### F08 PDF/PPT（后续）

- 验证文字型 PDF 的选区读取和页码定位。
- 扫描件需要 OCR，不包含在基础 MVP。
- Edge 内置 PDF 阅读器与普通网页权限不同，不能只靠普通内容脚本假定可用。
- 在 Edge 打开的 PPT 可能来自 Office 网页版或其他查看器，必须分别适配。
- 本地文件访问仅在实际需要时引导用户开启对应权限。
- 桌面软件取词需要额外桌面集成，明确延期。

### F09 AI“解释原句”与用户自填 API

- 默认关闭；未配置时点击入口跳转设置，不产生付费调用。
- 设置字段：启用开关、服务商、API Key、API 地址、模型名称、测试连接、保存配置、删除密钥。
- 预留 Gemini、DeepSeek、OpenRouter、自定义服务商。
- 自定义优先考虑 OpenAI-compatible 接口；Gemini 等独立协议由适配器处理，不假定所有服务协议一致。
- 选服务商后自动填建议地址，模型允许自行填写。地址和模型需在接入时核实，不把当前价格/模型名称写死。
- 测试连接必须显示真实结果，并说明测试可能消耗用户额度。
- 仅主动点击“解释原句”才发送目标词和必要的局部原句，不默认发送全文、完整课件或视频。
- 无原句时允许手动补充；否则只说明一般用法，明确缺少上下文。
- 建议输出：本句词义、整句翻译、一句简短用法说明。
- 建议关闭不必要的深度思考，限制输出长度，缓存“词＋上下文＋服务商＋模型＋提示版本”结果。
- 免费额度耗尽不自动切换付费服务，配置和调用都由用户控制。
- API 失败不影响普通查词、本地历史和收藏。

### F10 存储、导入和导出

- 收藏、历史、释义修改在本机持久保存；关闭浏览器后保留。
- 本地浏览器数据不等于永久备份；卸载扩展、清除数据或更换浏览器配置可能造成丢失，设置页提供简短说明与导出入口。
- 必须支持包含版本号的 JSON 导出与导入，排除 API Key。
- CSV 可作为后续增强，不替代完整备份格式。
- 导入校验格式、处理重复记录，失败时不破坏已有数据。
- 云端账户、登录及跨设备同步为后续选项，第一版无需后端。

## 7. 页面和界面状态

### 翻译浮窗

必要元素：原词、中文释义、收藏状态、收藏/查看记录、“解释原句”、关闭按钮。

可展开元素：原句、旧收藏释义、来源、追加本次语境。

必要状态：加载中、成功、词典未命中、已收藏、API 未配置、调用失败、当前页面不支持。

### 管理界面

建议分为“收藏”“查询历史”“设置”。设置包含快捷键说明、词典/联网备用配置、AI API 配置、导入导出和清除历史。

界面默认中文。风格简洁，操作按钮少，避免学习打卡、排行榜、强制复习提醒及自动全页高亮。

## 8. 建议数据结构

下列为概念模型，可根据实现优化。时间使用 ISO 8601，ID 稳定且唯一，文本字段使用 Unicode。

```ts
type Source = {
  type: 'web' | 'youtube' | 'pdf' | 'ppt' | 'manual';
  title?: string;
  url?: string;
  timestampSeconds?: number;
  pageNumber?: number;
};

type Occurrence = {
  id: string;
  originalText: string;
  meaning: string;
  context?: string;
  source?: Source;
  createdAt: string;
};

type VocabularyEntry = {
  id: string;
  language: 'en';
  canonicalForm: string;
  forms: string[];
  preferredMeaning: string;
  occurrences: Occurrence[];
  createdAt: string;
  updatedAt: string;
};

type LookupHistory = {
  id: string;
  originalText: string;
  canonicalForm?: string;
  meaning?: string;
  context?: string;
  source?: Source;
  status: 'success' | 'not_found' | 'error';
  createdAt: string;
};

type AISettings = {
  enabled: boolean;
  provider: 'gemini' | 'deepseek' | 'openrouter' | 'custom';
  baseUrl: string;
  model: string;
  // 密钥单独本地保存，不写入导出对象或日志。
};

type Backup = {
  schemaVersion: number;
  exportedAt: string;
  vocabulary: VocabularyEntry[];
  history: LookupHistory[];
};
```

收藏检查通过 canonicalForm 和可靠词形别名匹配；有歧义时保持分离。历史的“已收藏”状态建议根据当前词库计算，避免删除收藏后状态过期。

## 9. 技术与安全建议

- 建议使用 Manifest V3、TypeScript、内容脚本、后台 service worker 和扩展管理页。
- 内容脚本负责选区和浮窗；后台负责词典、存储、请求和服务商适配。
- 大词典和历史建议使用 IndexedDB；少量设置可使用扩展本地存储。
- API Key 仅本地保存，不使用同步存储，不写入单词备份、页面 DOM、日志或代码仓库。
- 本地保存不等于硬件级安全保险箱，不宣称密钥绝对不可提取。
- 请求由扩展后台发起，限制消息来源与参数，不向网页暴露通用 API 代理。
- 按需申请页面和 API 主机权限；不默认索取浏览历史、剪贴板、麦克风或全磁盘权限。
- 采用 ECDICT 等词典前核实词库来源、许可、署名及再分发条件。
- 微软翻译免费档需要用户自行配置；额度、开通条件以接入时官方说明为准。
- 词典候选：https://github.com/skywind3000/ECDICT
- 微软翻译参考：https://www.microsoft.com/en-us/translator/business/translator-api/
- AI 服务参考：https://ai.google.dev/gemini-api/docs/ 、https://api-docs.deepseek.com/ 、https://openrouter.ai/docs/

## 10. 验收标准

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| A01 | 打开英文文章并选词，不按快捷键 | 不自动翻译、不全页标记 |
| A02 | 选词后按快捷键 | 显示原词、释义和收藏状态 |
| A03 | 收藏后关闭并重新打开浏览器 | 收藏仍存在 |
| A04 | 再查已收藏词 | 显示已收藏和本次释义，可查看旧记录，旧释义不被覆盖 |

| A09 | 用英文或中文搜索 | 返回对应收藏记录 |
| A10 | 无上下文或来源 | 仍能查询和收藏原词、释义 |
| A11 | AI 未配置时点击解释 | 引导配置，不发起模型请求 |

| A16 | 断网或联网 API 限流 | 本地词典和收藏检查仍可使用 |

## 11. 未确定项与默认处理

- 正式名称、图标、颜色：未确定，可用简洁中性临时设计。
- 默认快捷键：开发时选可用组合，允许用户修改。
- 词库版本及打包大小：实现前评估，优先基础英汉覆盖。
- 查询历史保留上限：未确定，不静默制定会丢数据的规则。
- AI 默认模型和服务商：未选择，不自动启用或产生费用。
- 云同步供应商：未选择，不在 MVP 搭建。
- PDF/PPT 的具体阅读器：实现前检查实际平台，再决定适配策略。

## 12. 开发 AI 交付要求

1. 先交付阶段 A 的可加载 Edge 扩展和中文安装说明。
2. 明确列出已完成、未完成及不支持的场景。
3. 提供通过 edge://extensions 开发人员模式加载的步骤。
4. 按验收表验证核心流程，对 YouTube 和文档适配单独报告。
5. 不把占位按钮、模拟结果或未测试接口描述为真实完成。
6. 保持 API 适配、词典查询和存储模块独立，方便后续增加服务商、PDF/PPT、桌面取词及云同步。

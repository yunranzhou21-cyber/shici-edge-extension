# 拾词 v0.7.0

本版本将手动查词、单词补全、中文译英和文档阅读整合到同一个 Edge 扩展中。

- 手动查词输入英文前缀后显示本地候选及中文简释，支持点击、方向键、Enter 和 Tab 填入；补全不会自动联网、查询或收藏。
- 管理页和网页浮窗可切换“中文 → 英文”，使用已启用的微软 Translator 配置。英文译文可修改后收藏，中文原文作为释义；追加到已有词条时保留旧首选释义。
- 展开浮窗提供查词、收藏与设置，收起时保留可拖动的圆形图片图标。
- 支持可读取文字的网页文档和框架；内置 PDF 阅读器支持文字选区、页码与来源收藏、缩放、本地文件及在线 PDF。
- 扩展图标、单词本、设置、阅读器与浮窗采用深蓝和彩色渐变主题。
- 收藏、查询历史及备份保存在本机；英文查词优先使用随扩展打包的本地词典。

验证：36 项核心测试、23 项 Edge 集成检查、10 项浮窗检查、9 项文档/PDF 检查与 11 项补全/中文译英检查，共 89 项通过；语法、清单、图标与词典完整性检查通过。微软请求通过本机受控接口验证，没有使用真实 Azure Key 代用户验证云端订阅。

## 安装与更新

下载 [shici-edge-v0.7.0.zip](https://github.com/yunranzhou21-cyber/shici-edge-extension/releases/download/v0.7.0/shici-edge-v0.7.0.zip)，解压后在 `edge://extensions` 开启开发人员模式，加载其中的 `extension` 文件夹。

已有安装请先导出备份，在原来加载的扩展目录中替换新版文件，重新加载扩展并刷新网页，无需卸载。中文译英需要先保存并启用自己的微软 API 配置。

扫描 PDF 的 OCR、原始 DOCX/PPTX 文件解析、桌面应用取词和 YouTube 可选字幕面板尚未交付。含中文历史的备份请使用 v0.7.0 或更新版本导入。

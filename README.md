# 拾词 · Edge 主动查词与记录

根据 [产品需求](docs/requirements.md) 实现的阶段 A 扩展。没有后端、账户、打卡或自动全页标记。本地词典优先；微软联网备用与 AI 默认为关闭。

## v0.7.0：单词补全与中文译英

[下载 v0.7.0 安装包](https://github.com/yunranzhou21-cyber/shici-edge-extension/releases/download/v0.7.0/shici-edge-v0.7.0.zip) · [版本说明](docs/releases/v0.7.0.md)

管理页的“手动查词”和网页圆形图标展开后的“查词”页都支持：

- **英文补全**：输入 `appl` 等前缀，下拉显示最多 8 个本地词典候选及中文简释。点击候选填入，或用 ↑ / ↓ 选择、Enter / Tab 接受；接受后再按 Enter 或点击查询才真正查词。Escape 先关闭候选列表，再次按下可收起网页浮窗。中文输入法组词时不弹建议。
- **中文 → 英文**：将“翻译方向”切换为“中文 → 英文”，输入不超过 200 字符的中文词语或短句，点击翻译。使用已保存、启用的微软 Translator 配置；未配置、网络故障或限流会明确提示，不编造翻译。该方向没有离线整句翻译，英文查词继续保持本地优先。
- **收藏译文**：英文译文可修改；点击“收藏英文译文”后，英文作为词条、中文原文作为释义保存。若英文词形已存在，可追加本次中文释义，保留原有首选释义。英文词条最多 200 字符，较长的译文可先缩短再收藏。
- **历史与备份**：中文查询单独记录方向；可在历史中搜索中文原文或英文译文，点击“查看译文 / 收藏”再次打开。新版能导入已有英文备份；含中文历史的新备份应在 v0.7.0 或更新版本导入。
- **主动调用**：补全只读取本地词典，不联网、不记历史；选择候选、切换方向、输入中文均不触发翻译。只有提交查询才调用接口，微软请求只含输入文字，不含原句、网页或密钥 URL。缓存区分两个翻译方向，旧响应不会覆盖新词。

微软方向参数按 [官方 v3 Translate 文档](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/v3/translate) 实现，中文译英为 `from=zh-Hans&to=en`。已用独立 Edge 和本机受控接口验证协议及完整操作；没有使用真实 Azure Key 完成云端调用。

使用原扩展目录更新后，在 `edge://extensions` 点重新加载，再刷新网页；无需卸载。

## v0.5.0：浮窗手动查词与收藏（仅本地交付）

点击网页圆形“拾”图标，展开后默认进入 **查词** 页：输入英文单词或短语，按 Enter 或点击“查词”。结果显示本次释义和收藏状态；可直接修改中文释义，再点击“收藏”。未查到的词也能手动填写释义后收藏，原句可选。

- **已收藏**：仍显示本次查词释义，可展开“查看已有记录”；点击“追加本次原句 / 释义”保存新记录，保留原有首选释义。
- **收藏页签**：查看、搜索已经收藏的英文、中文释义和语境；这里的搜索只筛选收藏，不发起新的翻译。
- **联网与 AI**：查词沿用本地优先、已配置微软备用的规则，也可主动点击“微软联网查词”或“解释原句”。没有配置时提示去设置；输入或切换页签本身不会查询、联网或收藏。
- **记录方式**：手动输入的内容记录为手动来源，不自动附上当前网页作为出处。查询进入历史，只有主动点击收藏才写入单词本。
- **防止混淆**：修改待查询英文会清除旧结果；此前较慢的联网响应不会覆盖新词。切换查词、收藏、设置页签保留本次草稿；收起浮窗后未收藏的草稿不会保存。

本次只更新本地源码与 v0.5.0 安装包，没有上传 GitHub。沿用原扩展目录替换文件后，在 `edge://extensions` 重新加载，再刷新网页；无需卸载。

## v0.4.0：网页文档与 PDF（仅本地交付）

**使用 PDF**：单词本右上角点击“文档 / PDF 阅读”，或网页圆形图标展开后点击“文档 / PDF 阅读器”。选择本地 PDF，或粘贴在线 PDF 链接；选中英文后按原来的查词快捷键，也可点击“查询选中文字”。释义卡片沿用离线词典、微软联网重查、AI 原句解释和手动收藏，不会仅因选词就请求翻译。

- 支持带文字层的 PDF、翻页、页码跳转、75%–200% 缩放以及输入密码后打开加密 PDF。PDF.js 解析、文字层和图片渲染全部在本机运行，运行时不从 CDN 下载脚本。
- 收藏保留实际选词、释义、局部原句、文件名、页码和文件指纹。在线 PDF 还会记录来源链接；本地 PDF 的完整路径、文件内容和密码不进入收藏或 JSON 备份。
- 在单词本或浮框语境记录中点击 PDF 来源，可以重新定位到对应页。本地文件需要重新选择原文件，指纹不符会提示，避免把收藏定位到另一个同名文件。
- 在线链接会在主动打开时读取原站 PDF，不上传文档；受登录、重定向或站点权限限制时，会提示先下载再选择本地文件。支持 50 MB 以内文件；不申请全盘或浏览器本地文件访问权限。
- 扫描件/图片型 PDF 没有可选文字时明确提示“不含 OCR”。损坏文件、登录页伪装的 PDF、密码错误会显示真实状态。

**使用网页文档**：普通 DOM 文本、可访问的嵌入框架，以及使用 `role="document"` / `role="doc-page"` 的文档正文，可按快捷键选词。扩展会选择当前有焦点的文档框架，不再只读取最外层网页；密码框和普通输入区仍不取词。也增加了选中文字后的右键菜单“用拾词翻译并收藏所选英文”，能从浏览器提供的选区继续查询。

**Edge 内置 PDF**：普通内容脚本不能保证读取其选区。对常见 `.pdf` 地址按快捷键时，会转到拾词 PDF 阅读器；点击扩展图标后再打开“文档 / PDF 阅读”，也会尝试带入刚才 PDF 的地址。本地 PDF 需要在阅读器重新选择文件，无法直接从内置阅读器取得文件字节。PDF 链接的右键菜单也提供“在拾词阅读器打开此 PDF”。原生菜单是否出现在特定阅读器中仍受 Edge 版本限制，可靠路径是主动打开拾词阅读器。

**支持边界**：没有宣称适配所有 Office、腾讯文档、飞书或 Google Docs 页面。画布绘制、图片、受保护/无访问权限的框架、禁用复制的文档可能没有可读取的文字选区；这类文件可先导出 PDF 再打开。DOCX/PPTX 原文件、OCR 和桌面应用取词尚未支持。真实云文档平台未逐站验收；已在独立 Edge 中验证普通网页文档、跨源框架和 PDF 完整流程。

本次只更新本地源码和安装包，没有上传 GitHub。

## v0.3.0：微软联网查词

接入 Azure Translator Text v3。默认先查本地词典；启用微软备用后，本地未命中的单词或短语才会联网。结果卡片和手动查询区也提供“微软联网查词”，可以主动重查本地已命中的词。译文明确标记为微软翻译；微软提供机器翻译，不提供本地词典那样完整的词性、音标和多义项。

### 配置步骤

1. 在自己的 Azure 订阅中创建 Translator 资源，在该资源的“密钥和终结点”取得 Key、Endpoint 和区域。参见 [微软官方快速入门](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/quickstart/rest-api)。不要把 Key 发到聊天中。
2. 打开拾词设置 → **微软联网查词**，或网页浮框 → 设置 → **微软联网查词设置**。
3. 基础地址默认 `https://api.cognitive.microsofttranslator.com`；区域型或多服务资源按 Azure 页面填写区域代码，例如 `eastasia`，全局单服务资源可留空。自定义资源的 `https://资源名.cognitiveservices.azure.com` 会自动使用 `/translator/text/v3.0` 路径；也可填写已经含该路径的基础地址。
4. 填写自己的微软 Key，勾选启用，保存配置。浏览器按需请求该地址访问权限；保存不会调用接口，也不代表连接已通过。
5. 点击“测试微软连接”，确认后真实翻译一次 `hello`；会显示返回的译文或真实错误，可能计入 Azure 字符额度。免费档开通条件、额度、费用由你自己的 Azure 订阅决定，扩展不会自动购买、切换套餐或使用共享密钥。

联网查词只发送本次选中的词或短语，最多 200 字符，不发送网页全文、局部原句或来源链接。微软密钥与 AI 密钥分开存储，仅本机保存，不回填、不导出、不返回网页。更换 API 域名必须重新填写 Key；删除 Key 会关闭微软备用并清除微软缓存。

微软请求失败时，已有本地释义和收藏仍可使用；没有本地结果时显示连接、认证、权限或限流错误，可手动填写释义收藏。正常本地命中不会联网；缓存命中也不会重复请求。微软翻译与 AI“解释原句”是两个独立入口，不自动互相调用。

微软协议、缓存和失败降级已经通过单元测试与独立 Edge 中的本机受控 HTTP 服务验证。**尚未使用真实 Azure Key 完成云端成功调用**；安装后请用自己的资源运行真实连接测试。

## v0.2.0：网页圆形图标与浮框

普通 HTTP/HTTPS 网页会自动显示一个可拖动的圆形“拾”图标。点击展开收藏与设置，平时保持圆形；拖动不会误展开，位置在松开后保存，刷新页面或重启浏览器仍保留。点击页面空白、收起按钮或按 Escape 可收起面板。

- **收藏**：直接在网页查看和搜索英文、中文释义、原始词形与语境，点击来源可回原网页。需要编辑、删除、备份时打开完整单词本。
- **设置**：调整图标大小、透明度、重置位置、隐藏图标；也可切换已配置的主动 AI 解释。未配置 API 时会引导至完整设置，不会假装启用或发送请求。
- **快捷键**：原本已可在管理页修改；现在浮框“设置 → 修改快捷键”也能打开 `edge://extensions/shortcuts`。返回浮框后会读取当前绑定。组合键需在 Edge 自带编辑页更改。
- **重新显示**：隐藏图标后，点击浏览器工具栏的拾词 → 设置 → 网页圆形浮框 → 勾选显示并保存。

为常驻显示图标，此版本增加普通 HTTP/HTTPS 网页的内容脚本。请允许扩展在目标网站运行。脚本只显示入口、读取本地界面偏好，不扫描全文、不自动查词，也不调用 AI；收藏和设置面板使用扩展自己的页面，宿主网页无法读取其收藏列表或密钥。浏览器内部页面、商店、内置文档阅读器仍可能限制显示。

**从旧版更新**：先导出备份，在原先加载的扩展目录内替换为新版 `extension` 文件夹里的文件，然后到 `edge://extensions` 点重新加载，并刷新已有网页。若此前加载的是解压目录中的旧版副本，请更新那一份目录。无需卸载扩展；保留原目录可避免产生另一个扩展实例。

## 安装（Windows / Microsoft Edge）

无需安装 Node.js、Python 或其他开发工具。

1. 如果使用 ZIP，先解压整个文件；不要在压缩包里直接打开。
2. 在 Edge 地址栏输入 `edge://extensions`。
3. 开启左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择本项目的 **extension 文件夹**。该文件夹内直接包含 `manifest.json`。
   - 此工作区的目录：`D:\English-brower-tool project\extension`。
5. 如需固定图标，在 Edge 工具栏的扩展菜单中固定“拾词”。点击图标打开单词本。
6. 打开一个普通英文网页，选中 `running`，按 **Alt + Shift + D**。卡片会显示原词、一般中文释义和当前收藏状态。
7. 按 Escape 或点击卡片右上角关闭。收藏前可以修改中文释义；查询本身只加入历史。

默认组合已在独立 Edge 测试环境确认成功注册；其他扩展、输入法或系统软件仍可能占用。到 `edge://extensions/shortcuts` 修改“查询选中的英文单词或短语”，或使用设置页的快捷键按钮。不读取密码框、普通输入区或剪贴板；可访问框架及语义文档编辑区按本节支持边界处理。

更新文件后，在 `edge://extensions` 点击扩展的重新加载按钮，再刷新已打开的网页。保留同一扩展目录和浏览器配置；更新前建议导出备份。不要通过卸载重装来更新，否则可能丢失本地数据。

## 日常操作

- **网页选词**：选中英文后按快捷键；没有选区时提示，不保存空历史。
- **手动查词**：网页圆形图标 → 查词，或单词本右上角“手动查词”。短语可以输入，但词库不保证命中任意短语或句子。
- **收藏**：修改本次释义后点击收藏。再次查询仍显示本次词典结果；“查看已有记录”查看旧释义，“追加”保存本次语境。旧首选释义不会被自动覆盖。
- **词形**：`run/runs/running/ran` 等已审查的常见形式归为同一词条，同时保留遇到的拼写。`saw/left/rose` 等歧义词不强行归并。没有词尾猜测算法，不保证所有词形都能归并。
- **历史**：查过但未收藏的词也会保留。删除或清空历史不会删除收藏；删除收藏也不会删除历史。没有静默清理上限。
- **搜索**：支持原词、标准词形、中文释义、语境和来源标题。大量结果每次显示 100 条，可继续加载，搜索仍覆盖全部数据。
- **来源**：可获取时记录标题和链接；YouTube 时间点可记录时，来源链接带时间参数。来源或原句为空不影响收藏。
- **备份**：设置 → 导出 JSON；导入同格式文件会合并重复 ID 与词条，保留已有首选释义。版本号无效、字段错误或不安全链接会拒绝导入，原数据不变。API 密钥与配置不包含在备份中。

## AI 设置（完全可选）

1. 到“设置”，选择 Gemini、DeepSeek、OpenRouter 或自定义兼容接口。
2. 服务商选择后填入建议基础地址；模型名由你根据服务商当前文档填写。本扩展不内置默认模型或价格。
3. 填入你自己的 API Key，按需勾选启用，然后保存。浏览器会请求该 API 站点的访问权限。拒绝权限则不保存配置。
4. “测试已保存配置”会发送一次真实模型请求，可能消耗额度；界面先明确确认。保存设置本身不发送请求，保存成功也不表示连接测试通过。
5. 只有点击查词卡片或手动查词区的“解释原句”，才发送目标词和必要的局部原句，最多 1,000 字符。没有原句时可先补充，否则请求一般用法。
6. 密钥不回填，不写日志、不同步、不导出。删除密钥会同时清除解释缓存。更换服务商或 API 域名需要重新填写对应密钥，避免复用旧服务密钥。

适配器已按官方协议实现，并通过响应格式测试；自定义兼容接口已通过本机 HTTP 测试服务验证实际请求、缓存、429 错误及删除密钥。**尚未使用真实云端密钥完成 Gemini、DeepSeek、OpenRouter 的线上验证。** 服务可用性和模型权限请以你的真实连接测试结果为准。自定义基础地址不包含末尾 `/chat/completions`；HTTPS 以外仅允许本机 `localhost` / `127.0.0.1`。

解释结果仅在后台内存中最多缓存 100 项，缓存键包含词、原句、服务商、地址、模型与提示版本。后台休眠或浏览器关闭后缓存可能消失；这不影响收藏或历史。API 失败不会关闭离线查词，不会切换到其他服务。

## 已完成与限制

**阶段 A 已实现**：主动快捷键路径、轻量卡片、离线中文释义、收藏检查、手动收藏与追加、保守词形归并、历史、单词本编辑删除、中英文搜索、JSON 导入导出、API 设置与解释入口、真实请求适配及错误状态。

**后续**：YouTube 可选词字幕面板与字幕提取、特定 Office/PPT 平台适配、OCR、桌面取词、手动合并词条、CSV、云同步。

**YouTube 当前行为**：用户能选中的网页文字可走普通查词路径；该路径会尝试暂停页面视频并记录秒数，关闭卡片不会自动播放。字幕面板、字幕读取与无字幕状态识别尚未交付，真实 YouTube 视频也尚未验收。字幕不可选时请使用单词本手动输入，不上传音视频，不做自动语音识别。

**文档当前行为**：PDF 使用扩展自己的本地阅读器；网页文档支持可读取的 DOM/框架选区。Edge 原生 PDF 选区和画布型阅读器不能保证直接取词，使用本地阅读器或手动入口。此版本不请求全盘或浏览器本地文件访问权限。

本地浏览器数据不等于永久备份。卸载、清除扩展数据、更换配置或设备可能造成丢失，请定期导出。

## 模块结构

`extension/manifest.json` 为可直接加载的 MV3 入口，无构建步骤。`content.js` 负责选区、查词卡片、圆形图标和拖动；`widget.*` 为扩展域内的浮框收藏与设置页；`background.js` 验证消息、协调词典与数据；`lib/preferences.js` 校验界面偏好；`lib/core.js` 负责数据与归并；`lib/storage.js` 使用 IndexedDB 事务存储；`lib/dictionary.js` 按首字母加载本地词典；`lib/providers.js` 提供独立服务商适配；`manager.*` 为中文管理页。

当前词典包含 **37,019 词条**，词库约 **2.6 MiB**，来自 ECDICT 已固定提交的常用词子集。筛选条件和原始 CSV 校验摘要见 `extension/data/metadata.json`。若需重新构建词库，运行 `python tools/build_dictionary.py`；此开发步骤需要网络，扩展运行不需要下载词典。

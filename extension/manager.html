网页受限、文档阅读器或字幕不可选时，也可以在这里输入。

网页圆形浮框

普通网页自动显示圆形图标，点击查看收藏与设置，拖动可调整位置。显示图标不会自动查词。

快捷键与页面支持

在普通网页选中英文后按 Alt + Shift + D。仅在触发时读取选区和附近文字，不读取剪贴板或输入框。

快捷键若被其他扩展占用，请自行重新绑定。内置 PDF、Office/PPT、浏览器内部页、商店页面及嵌入框架可能无法取词，请使用手动查词。YouTube 字幕面板适配尚未交付；可选中的网页文字仍可查询，主动查词会暂停视频，之后需手动播放。

一般释义不代表当前语境的唯一含义；常见可靠词形合并，歧义词保持独立。本地优先；只有启用微软联网备用后，未命中的词才会联网。也可在结果卡片主动点击“微软联网查词”。

微软联网查词 Azure Translator

默认关闭。启用后，仅主动查询且本地未命中时调用微软；“微软联网查词”按钮可主动重查已命中的词。只发送选中的单词或短语（最多 200 字符），不发送原句或网页正文。微软提供机器译文，不是完整词典。费用和免费额度以你自己的 Azure 订阅为准，不会自动切换套餐或服务。

微软 Key 与 AI Key 分开，仅存本机，不导出、不返回网页。更换 API 域名需重新填写 Key。保存配置不调用接口，测试连接会发送 hello，可能计入字符额度。微软配置文档 ↗

AI 解释原句 可选

只有点击“解释原句”时，才发送目标词与最多 1,000 字符的局部原句。连接测试也会发送一次真实请求，可能消耗额度。请先在服务商处核实当前模型与价格。

密钥仅保存在本机扩展存储，不同步、不导出；本地存储并非硬件安全保险箱。更换服务商或 API 域名需要重新填写密钥。保存时浏览器会按需请求该站点访问权限。

数据与备份

收藏与历史保存在本机，关闭浏览器后保留。卸载扩展、清除扩展数据或更换浏览器配置可能导致丢失，请定期导出。

备份含版本号、收藏和历史，不含 API Key 或设置。导入合并重复记录，保留已有首选释义；无效文件不会修改原数据。
